# Frontend Data Contract

The frontend does NOT process raw data. It strictly consumes outputs generated by `analysis/notebooks/wec_analytical_foundation.ipynb`.

## Chapter 01: The Anatomy
**Data Object**: `dataset_scale.json`
- **Source**: Aggregated from `df_raw` (deduped).
- **Fields**: `total_events` (int), `total_entries` (int), `class_distribution` (Array<{class: string, count: int}>)
- **Unit**: Count of events and car entry rows.
- **Intended Visualization**: Multi-dot scatter separating into class clusters.

## Chapter 02: The Last Manufacturer Standing
**Data Object**: `top_class_wins.json`
- **Source**: `df` filtered to `class_group == 'Top Class (LMP1/Hypercar)'`.
- **Fields**: `season` (string), `event_id` (string), `team` (string), `is_toyota` (boolean), `cumulative_wins` (int).
- **Unit**: Unique race events (overall_position == 1).
- **Intended Visualization**: Cumulative step-chart of Toyota vs Rest.

## Chapter 03: The Armada Effect
**Data Object**: `gt_dominance.json`
- **Source**: `gt_team_stats` dataframe.
- **Fields**: `team` (string), `absolute_wins` (int), `unique_vehicles` (int), `wins_per_vehicle` (float).
- **Unit**: Class-position wins across unique events.
- **Intended Visualization**: Barbell / Dot plot comparing absolute wins to participation volume.

## Chapter 04: The Grip
**Data Object**: `tyre_share.json`
- **Source**: `df['tyres']` aggregation over time.
- **Fields**: `season` (string), `michelin_pct` (float), `dunlop_pct` (float), `other_pct` (float).
- **Unit**: Valid car entry assignments (denominator: 3,011).
- **Intended Visualization**: 100% Stacked Area Chart.

## Chapter 05: The Evolution of Speed
**Data Object**: `circuit_evolution.csv` (specifically filtered for Le Mans)
- **Source**: `circuit_evolution` export.
- **Fields**: `season` (string), `class_group` (string), `min_fastest_lap_time_sec` (float).
- **Unit**: Seconds (minimum recorded lap per class per event).
- **Intended Visualization**: Line chart with era annotations (LMP1 vs Hypercar).
- **Known Caveats**: Weather/BoP impacts pace independently of engineering. Must be heavily annotated.
